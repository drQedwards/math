# 3-SAT is decided exactly, not in polynomial time

**Author:** Dr. Q

**Date:** 6 October 2026

**Decision:** every finite 3-CNF is decided by search. The procedure is not a polynomial-time algorithm, and it does not settle P versus NP.

The code in `src/three_sat.py` was checked against exhaustive search for every random instance in `tests/test_three_sat.py`.
